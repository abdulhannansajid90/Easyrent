pnpm dev

bun dev

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Database & Admin Setup

Before running the application, make sure you have connected your PostgreSQL database and set up your `.env` file with `DATABASE_URL`.

Once the database is connected, generate the Prisma client and run the seed script to create the initial admin user:

```bash
npx prisma generate
npx prisma db push
npx prisma db seed
```

**Default Admin Credentials:**
- **Username:** `admin`
- **Password:** `EasyRent2026!`
